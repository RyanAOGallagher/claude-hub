claude-hub — five UI directions

Static mockups, current palette. Each is a direction, not a spec — mix and match.
01

Live Rail

the sidebar becomes a status board

Same layout you have, but the list is sorted by life, not alphabet: open sessions on top with their status dots and a one-word state, recently-touched next, everything else compressed and dimmed. The sidebar answers "what's going on?" before you ask.

Palette

no sidebar at all

04

Unified Rail

tabs and projects merge; no tab bar

One column holds everything: open sessions render as raised cells (status dot, close on hover), a hairline, then the plain project list. Clicking a project turns its row into a cell. The top tab bar disappears — the terminal gains 40px and the window reads as two clean surfaces.

05

Garage

a start screen, since the app finally has somewhere to start from

When no tab is open (or via a Home button): a card grid built from the _hub briefs — the one-line "What", status, last-touched — plus a dashed "today" card showing the daily log so far. The GUI stays dumb: it just renders markdown the hub already maintains. Click a card, get a session.
