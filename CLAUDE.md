# claude-hub

Tiny Electron GUI for running Claude Code or Crush sessions: the harness is selected by config.json `harness`; the hub PM session runs in the folder set by `hub` (default: `_hub/` inside the first group; currently `~/Desktop/projects/_hub`) plus per-project tabs. Keep it dumb - conventions live in the markdown, not the app.

## Hub brief
Read `../_hub/claude-hub.md` before starting work — it holds this project's current state and decisions. Before ending a session: update that brief with what changed, and append `- [claude-hub] <what you did>` to today's log at `../_hub/log/YYYY-MM-DD.md` (create the file if missing).
